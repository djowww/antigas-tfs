# Comunicação de vulnerabilidades

Use [Report a vulnerability](https://github.com/djowww/tibia-7.4-a-classic-rpg-version/security/advisories/new) para enviar um relato privado aos mantenedores.

Inclua a versão ou commit afetado, o componente, os passos de reprodução e o impacto observado. Use dados fictícios e remova senhas, chaves, tokens e informações de jogadores de qualquer evidência.

Discussões públicas de bugs comuns podem ser abertas em [Issues](https://github.com/djowww/tibia-7.4-a-classic-rpg-version/issues). Aguarde a avaliação dos mantenedores antes de publicar detalhes de exploração de uma vulnerabilidade.

As correções são desenvolvidas na branch `main`. Versões antigas e instalações com modificações próprias precisam ser avaliadas individualmente.
