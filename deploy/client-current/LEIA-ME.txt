ANTIGAS 7.4 — CLIENTE v42

INSTALAÇÃO
1. Extraia todo o conteúdo deste ZIP para uma pasta própria, sem misturá-lo com outra instalação do cliente.
2. Mantenha data, modules, init.lua, os executáveis e as DLLs juntos na mesma pasta.
3. Inicie Antigas_gl.exe. Se houver incompatibilidade com o driver gráfico, tente Antigas_dx.exe.
4. O site oficial é https://tibia74.tech.

IMPORTANTE
- Não renomeie nem mova data, modules ou as DLLs: o cliente depende desses caminhos relativos.
- Não remova arquivos para “limpar” a instalação. Este pacote já contém apenas os componentes de execução e este guia.
- Feche o cliente antes de substituir arquivos durante uma atualização.
- Não compartilhe logs que possam conter dados técnicos da sua sessão; envie-os apenas ao suporte oficial quando solicitado.

CONQUISTAS
- Abra Achievements no painel lateral para consultar os 60 objetivos, progresso e recompensas do personagem.
- Use All objectives, In progress e Completed; o segundo filtro permite escolher a categoria.
- O botão fica destacado quando uma nova conquista é concluída. Clique no cabeçalho do painel lateral para recolher ou expandir os botões.

GAME VIEW
- Options > Interface: Classic (15 x 11) ou Widescreen (mapa adicional, sem deformar tiles).
- Options > Graphics: Left panels e Right panels continuam disponíveis.
- Widescreen se adapta ao espaço entre os painéis. Em servidores sem suporte, usa Classic.
- Sprites, equipamentos, minimap e chat mantêm o estilo clássico.

Menu lateral: clique no cabecalho Menu [-] para recolher e Menu [+] para
expandir. Novas conquistas continuam destacadas no cabecalho recolhido.
